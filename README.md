# Nuevos Aires — demo

Static client demo for **Nuevos Aires, Las Grutas**.

## Deploy on Vercel

1. Import `Seba-P1/Nuevos-Aires-Demo` in Vercel.
2. Leave the framework preset as **Other**.
3. Deploy — Vercel serves `index.html` without a build step.

The site is intentionally marked `noindex, nofollow` because it is a presentation demo.

## Local preview

```bash
npx serve .
```
